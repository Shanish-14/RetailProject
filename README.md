# Retail Sales & Customer Analytics Dashboard

## Project Overview
An interactive Retail Sales & Customer Analytics Dashboard developed using **Microsoft Power BI** to analyze retail sales performance, customer purchasing behavior, and product trends. The project uses RFM analysis to segment customers and generate meaningful business insights.

## Key Features
- **Sales Analysis:** Track total sales, quantity, and transactions.
- **Customer Segmentation:** Identify Champions, Loyal Customers, and Potential Customers using RFM analysis.
- **Sales Trends:** Analyze monthly sales performance.
- **Product Analysis:** Identify top-selling products and product categories.
- **Interactive Dashboard:** Explore insights using slicers and filters.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling
- RFM Analysis

## Key Analytical Techniques
- Recency – How recently a customer made a purchase.
- Frequency – How often a customer purchases.
- Monetary – How much a customer spends.

## Project Objectives
- Understand customer purchasing patterns.
- Identify valuable customer segments.
- Analyze sales performance and trends.
- Support data-driven business decisions.
